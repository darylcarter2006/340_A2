About This Website

This website is a class project built around "The Amazing World of Gumball". I chose it because it has a large cast of colorful, easy-to-describe characters. It started as a static HTML and CSS gallery in Assignment 2, became a REST API with a database in Assignment 3, and in Assignment 4 the two are joined: the search bar and the form now really work.

You can browse every character in the gallery, search by name, filter by species, open a character's details page, add a new character, edit an existing one, and delete one after confirming. Every change is saved in the database.

How This App Is Built

The app is one Spring Boot service with three layers. A repository (Spring Data JPA) reads and writes the characters table in a Neon PostgreSQL database. A service holds the rules, such as filtering and updating. A REST controller exposes the service as JSON at /api/characters.

The pages you are looking at are plain HTML files that Spring Boot serves from the same app. Each page runs a small JavaScript module that calls the API with fetch, then builds the page in your browser from the JSON it gets back. All of the fetch calls live in one file, api.js, and one shared script builds the navigation bar on every page. Because the pages and the API come from the same origin, no extra configuration is needed, and the whole thing deploys as a single Docker service on Render.
